# 本地音色参考库

这里保存了 6 段普通话参考录音，每段都附有对应原文。可供当前 CosyVoice 3 使用，无需下载新模型或重新训练。

双击 `音色试听.html`，可以试听参考录音和 CosyVoice 合成示例。

## 使用方法

1. 先试听，选择喜欢的参考声音。
2. 在桌面程序的“配音声音”下拉菜单中选择相应样本。
3. 软件会同时使用样本的参考录音和原文；可以先点击“试听参考”。
4. 输入需要朗读的文字，点击“生成语音”。

文本配音和 PPT 配音共用这份音色库。参考录音决定声音特征，原文帮助模型理解录音；自建音色时两项应一起填写。
