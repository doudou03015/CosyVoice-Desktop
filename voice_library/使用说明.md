# 本地音色参考库

安装包不再内置旧版 FLEURS/AISHELL-3 参考音色。这样新电脑安装后不会自动选择不需要的声音，也不会因旧安装残留而重新出现。

请在桌面程序的“音色库”中直接录制新音色，或导入你有权使用的参考录音和对应原文。文本配音与 PPT 配音共用同一份音色库；录音可以保存为长期音色，也可以只在当前稿件临时使用。

软件会校验采样率、时长、静音和文件路径。用户数据保存在系统用户数据目录，不会提交到 GitHub 或自动上传。

## 本机新增的三款参考声音

示范音色1、示范音色2、示范音色3是用户选定的 CosyVoice 3 官方演示参考录音，目前只保存在已验证电脑的用户数据目录中，未放入公开安装包。迁移到另一台电脑时，关闭软件后把旧电脑用户数据中的 `voices/local-presets` 文件夹复制到新电脑用户数据的 `voices` 文件夹，再启动软件。

三款稳定 ID：

- `cosyvoice_demo_longwan_zh`：示范音色1（Longwan 中文样本）
- `cosyvoice_demo_longshu_zh`：示范音色2（Longshu 中文样本）
- `cosyvoice_demo_longcheng_zh`：示范音色3（longcheng 示例）

公开安装包是否内置这些音频仍以取得明确的再分发许可为前提。没有许可时请使用本机导入或录音功能。
