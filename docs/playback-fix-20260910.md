# 本机试听修复与应用图标

2026-09-10，本机修复构建，未替换已发布的 alpha.1 附件。

试听每次重新绑定系统默认音频输出，并响应运行期间的设备变化。
增加独立的播放状态、进度、设备名与错误提示，避免失败仅写入设置日志。
Windows EXE、安装器、快捷方式、任务栏、窗口标题与侧栏采用统一图标。
ICO 包含 16、24、32、48、64、128、256 像素七档透明图像。

验证环境：Windows、PySide6/Qt 6.11.2；53 passed、20 subtests passed。
源码和最终冻结 EXE 均对实际生成的 24 kHz、11.4 秒 WAV 执行播放验证：
进入 PlayingState/BufferedMedia，播放位置超过 2 秒，没有播放器错误。
这确认了解码和输出管道正常；实际听感仍以用户的扬声器输出为准。
正常与最小窗口完成图标和播放状态布局检查。

可通过以下命令复查安装版的播放管道，不会加载语音模型：

```powershell
.\CosyVoice-Desktop.exe --verify-playback --audio "配音.wav" --report "播放检查.json"
```

检查会播放开头约 3 秒，并在报告记录播放器状态、输出设备、进度和错误。
