# CosyVoice 配音工作台 0.1.0-alpha.1

首个 Windows 桌面测试版：把普通文本配音、音色管理和 PPT 讲解视频放入独立窗口，
继续使用 CosyVoice 3 0.5B 本地模型。

## 本版提供

- TXT/DOCX 文本导入，长文本分段配音，试听及 WAV/MP3 导出。
- 6 段带来源和许可的预设参考样本，自建音色与临时录音。
- PPTX 备注读取、外部逐页讲稿映射预览、单页编辑、音色/语速覆盖与批量配音。
- PowerPoint 静态页面渲染及 1080p30 H.264/AAC 视频；空页默认 3 秒、隐藏页默认排除。
- 工程资源副本、已完成音频复用、取消重试、草稿恢复与本地诊断导出。
- 自动检测 RTX 架构、显存与驱动；RTX 20～40 和 RTX 50 使用独立的运行组件。
- 组件固定版本、分片下载与 SHA-256 校验；真实 CUDA 运算、模型短句及编码自检。

## 下载

普通用户下载名称以 `windows-x64-setup.exe` 结尾的安装器，或使用 `portable.zip`。
首次打开后到“设置”选择组件位置，自动准备组件并执行自检。
运行包分片由程序组合，普通用户无需手工解压；模型从官方固定修订下载，支持校验复用。
无需全局 Python 或 FFmpeg；PPT 视频功能需要用户已安装 Microsoft PowerPoint。

本版未进行商业代码签名。发布附件提供 SHA-256 校验文件。
源码包、第三方许可证及适用的对应源码附件用于审阅和重新构建。

## 验证范围

当前开发设备是 RTX 2070 Super 8 GB。自动化测试覆盖显卡分类、下载、文稿、音色、
工程恢复、界面流程与工作进程消息。20 页 PowerPoint 实测保持原文件 SHA-256 不变，
19 页有效页面导出为 1230 帧，视频与音频时长同为 41 秒；该计时测试使用测试信号。
真实模型语音验证另行记录，见仓库验收文档。

RTX 30、4070 Ti Super、其他 RTX 40、RTX 50 与符合条件的笔记本仍为
**目标兼容、待实机验证**。运行包可以安装、torch 可以导入，都不能代替对应显卡实际模型合成。
尚未完成计划要求的代表性显卡验收，因此本次标为预发布，不发布正式兼容承诺。

首版范围为 Windows 10/11 64 位、RTX 20/30/40/50 的 8 GB 及以上版本。
4/6 GB 显卡、GTX、AMD、Intel 与 CPU 配音不在范围内。
PPT 动画、转场和嵌入视频的动态内容不还原。
