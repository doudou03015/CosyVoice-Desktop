# CosyVoice 配音工作台 v0.1.0

首个正式版本，整合 alpha.1 之后的音色管理、直接录音、试听、窗口显示和配音衔接修复。

## 下载和升级

普通用户下载 `CosyVoice-Desktop-0.1.0-windows-x64-setup.exe`，或解压便携包使用。
已有安装请先保存任务并关闭软件，再安装到原程序目录。保留原模型、运行组件、音色、工程和生成结果；
本机配置的 `app-data-location.json` 在覆盖安装时保留。不要删除原数据目录。

首次在其他电脑使用时，到“设置”自动准备组件并运行完整自检。无需全局 Python 或手动选择 CUDA 版本。
本版复用原 Release 的固定运行组件，安装器按清单下载并校验，无需先安装 alpha.1 软件。
模型从官方固定版本下载，两套运行组件共用一份模型。PPT 视频功能需要已安装 Microsoft PowerPoint。

## 本次更新

- 预设和自建音色均可删除，预设可选择恢复；删除不会替换现有草稿和工程已保存的声音。
- 支持软件内按稿录音、试听、重录、保存为音色或临时使用；修复部分 Windows 数据目录下无法保存的问题。
- 试听跟随系统默认音频输出，并显示播放状态和错误。
- 中文长讲稿优先在完整句子处划分批次，缩短批次接缝处过长的静音，保留句内自然停顿。
- 统一软件、任务栏和窗口图标；窗口按主屏可用区域居中。
- 支持明确指定共享用户数据目录，避免不同启动方式显示不同的音色库。
- 窗口标题、侧栏、程序文件属性和安装器显示统一版本号。

## 验证范围

RTX 2070 Super 8 GB 已完成本机桌面配音、长文本、PPT 视频、播放和录音相关验证，用户已确认本机使用无问题。
其他 RTX 20、RTX 30、RTX 4070 Ti Super 和其他 RTX 40、RTX 50、符合条件的笔记本仍为
**目标兼容、待对应实机验证**；正式版本号不代表所有目标显卡都已完成测试。
具体状态见 [兼容与验收表](../compatibility.md)。

目标系统为 Windows 10（1809 及以上）/11 64 位；首版显卡范围为 RTX 20/30/40/50 的 8 GB 及以上型号。
4/6 GB、GTX、AMD、Intel 与 CPU 配音不在首版范围。
PPT 视频使用静态页面，不还原动画、转场或嵌入视频的动态内容。

## 组件和许可

公开包仅包含已附许可和来源的参考样本及独立自检录音。龙婉、龙书、龙橙的本机演示录音、
用户录音、讲稿和工程不随公开包分发；本机已有音色继续保留。

`component-manifest.json`。这只是独立组件版本，桌面程序版本为 `0.1.0`。
