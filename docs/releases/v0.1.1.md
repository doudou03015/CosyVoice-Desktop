# CosyVoice 配音工作台 v0.1.1

修复 v0.1.0 在新电脑首次准备模型时出现的 **HTTP Error 401: Unauthorized**。
原组件清单将 ModelScope 的 WeText 文件误写为 Hugging Face 下载地址；原电脑已有这些文件，首次下载故障未被覆盖。
本次将四个固定版本、SHA-256 已核验的 WeText 文件直接随程序提供，按 Apache-2.0 附带来源和许可证。

## 如何升级

1. 下载 `CosyVoice-Desktop-0.1.1-windows-x64-setup.exe`。
2. 关闭旧版软件，覆盖安装到原程序目录；无需先卸载。
3. 打开“设置”，保留原组件位置，点击“自动准备所需组件”，完成后运行完整自检。

**不用把所有内容重新下载。**已安装且校验通过的组件直接复用；下载缓存保留原组件版本和 SHA-256 文件名，
完整文件校验后复用，未完成文件尝试续传。只有缺失、校验失败、缓存已被清理或服务器不支持续传的文件需要补下载。
不要手动清理系统 Temp 中的 `CosyVoice-Desktop-downloads`。设置、音色、讲稿、工程及生成结果不因升级删除。

## 其他改进

- 下载和校验显示真实文件名、连接状态及缓存复用状态，不再反复显示一长串哈希值。
- 网络超时、断流和临时服务器错误会有限重试；已下载部分继续保留。
- 错误提示显示文件、服务器和 HTTP 状态，不输出带签名的临时下载地址。
- 恢复安装时按尚需下载的内容估算空间，避免重复计算完整缓存的下载占用。
- 发布检查增加空缓存完整模型安装、进程重启复用和断网缓存恢复，不再仅验证已有模型。

## 组件和兼容范围

模型、两套 CUDA 运行环境和 FFmpeg 的版本及文件校验值保持不变。本次没有升级推理依赖。
已实机验证的设备仍为 RTX 2070 Super；4070 Ti Super、其他 RTX 20/30/40/50 及笔记本继续按
[兼容表](https://github.com/doudou03015/CosyVoice-Desktop/blob/desktop/docs/compatibility.md) 标注，未增加未经验证的兼容声明。

运行组件复用 `v0.1.0-alpha.1` 的固定分片，位置和校验值见 `component-manifest.json` 及 `EXTERNAL-COMPONENTS.json`。
第三方依赖版本未变，对应源码继续由
[固定第三方源码附件](https://github.com/doudou03015/CosyVoice-Desktop/releases/download/v0.1.0-alpha.1/third-party-sources-0.1.0-alpha.1.zip)
提供（1,068,653,110 字节，SHA-256 `d4b448575c0a1598656d4fd917db1369b8a89b47c418b1266b86ce9bbfac94c9`）。
新的许可证附件补充了 WeText 来源和许可。安装器未进行代码签名。

具体构建和验收结果见附件 `BUILD-RELEASE.md`、`VERIFICATION.json` 与 `SHA256SUMS.txt`。
公开包不包含本机录音、用户资料或许可尚未确认的三款演示音色。
