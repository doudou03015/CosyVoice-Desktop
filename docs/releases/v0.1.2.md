# CosyVoice 配音工作台 v0.1.2

本版将旧安装包中的六段 FLEURS/AISHELL-3 参考音色从产品中移除。新安装包不再携带这些文件；升级时程序也会永久忽略旧 `_internal/voice_library` 中的残留 ID，不显示、不自动选择，也不提供恢复入口。这样新电脑首次启动不会再误用旧音色。

龙婉、龙书、龙橙是此前电脑上的本机音色。由于公开再分发许可未确认，它们没有放进 GitHub 安装包。要在另一台电脑继续使用，请关闭软件，把旧电脑用户数据目录下的 `voices/local-presets` 文件夹复制到新电脑用户数据目录下的 `voices` 文件夹；也可以在音色库逐项导入录音。不要覆盖新电脑的 `settings.json`，其中可能有旧盘符。

模型下载修复、缓存续传、WeText 内置资源和所有组件版本保持 v0.1.1 不变；已完成缓存无需重新下载。

验证：全套桌面测试、真实 CUDA 配音、NVENC 视频编码、主屏居中和图标检查均通过。公开安装包不包含用户录音、工程和本机三款音色。
