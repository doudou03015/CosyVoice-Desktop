# CosyVoice 配音工作台 v0.1.3

## 变更

- 支持导入 M4A 参考录音，合成前由 FFmpeg 转为单声道 24 kHz WAV。
- 文本配音结果支持导出 M4A（AAC 192 kbps），同时保留 WAV 和 MP3 导出。
- 组件下载清单随本版本发布，运行包分片使用本版本 Release 的地址和校验值。

## 兼容性

- Windows 10/11 64 位，RTX 20～50 系列 8 GB 及以上目标范围。
- RTX 2070 Super 已完成本机验证；其他型号以安装后的完整自检结果为准。
- M4A 导入和导出需要随组件提供的 FFmpeg；缺少 FFmpeg 时软件会显示明确提示。

## 许可

本版本不在公开安装包内新增未确认再分发许可的官方演示音频。模型、Qt、FFmpeg 及其他组件的许可资料见随附文件。
