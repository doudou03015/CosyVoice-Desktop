# 音色管理与直接录音

## 使用

“音色库”中的“删除音色”适用于预设和自建音色。预设从本机列表移除，
不会删除安装包原文件；“恢复预设”可勾选放回。隐藏状态在重启、升级后继续保留。
自建音色删除其库内文件，当前稿件和已保存工程的参考副本及生成结果继续可用。

点击“录制新音色”，选择麦克风并按窗口中的文字朗读。麦克风仅在点击“开始录音”
后采集；录音时软件停止试听，不向扬声器实时回放。结束后可试听、修改与录音对应的
原文或重录，再命名保存。建议 3～15 秒，30 秒自动停止，不足 3 秒、静音或无效音频
不能保存。程序不转写录音，也不上传声音。

文本配音和 PPT 配音的“直接录音”打开同一窗口，确认后作为该稿件的临时参考，
无需加入音色库。文本草稿自动保留参考副本；PPT 保存工程时一起保存。合成、导出
期间不能开始录音或删除音色。音色库为空时仍可导入、编辑和保存 PPT；生成有旁白的
页面前再选择或录制声音。显卡自检使用独立内置参考，与可见音色列表无关。

无麦克风时连接设备后再选择。若系统拒绝访问，请在 Windows 的“隐私和安全性 →
麦克风”中允许桌面应用访问；设备断开、没有收到数据或静音时窗口会说明原因。
关闭或取消窗口会释放麦克风并清理本次临时音频。

## 本机新增的三款参考声音

以下固定使用用户选定的官网样本，以原文配合当前 CosyVoice 3 0.5B 模型做参考合成，
不更换模型。它们排在原六项前，沿用稳定 ID；重新导入或未来升级不会恢复已删除项。

| 音色与稳定 ID | 固定样本 |
|---|---|
| 龙婉 · Longwan / `cosyvoice_demo_longwan_zh` | [Longwan 中文](https://qwenaudio.github.io/cosyvoice3/audio/c3_large/SFT/minority_langugae/sft_longwan_zh.wav) |
| 龙书 · Longshu / `cosyvoice_demo_longshu_zh` | [Longshu 中文](https://qwenaudio.github.io/cosyvoice3/audio/c3_large/SFT/minority_langugae/sft_longshu_zh.wav) |
| 龙橙 · longcheng / `cosyvoice_demo_longcheng_zh` | [longcheng 示例](https://qwenaudio.github.io/cosyvoice3/audio/c3_large/SFT/00004506-00000103.wav) |

“参考录音”播放选定样本，“合成示例”播放本机用同一段讲稿生成的声音：

> 大家好，欢迎收听今天的讲解。接下来，我们会按照页面顺序，介绍主要内容、关键步骤和需要注意的事项。

2026-09-14 已在 RTX 2070 SUPER 8 GB、Python 3.10.21、PyTorch 2.3.1+cu121 上
分别合成成功，语速 1、种子 0。龙婉、龙书、龙橙的输出时长分别为 9.56、8.84、
8.04 秒。技术合成验证通过，用户已确认这三段本机示例可以保留；参考复刻不等同于网站的微调模型。

元数据保留网页原文、样本 URL、原文件 SHA-256、参考文件 SHA-256、处理记录和
本机合成环境。处理只把声道平均转换为单声道 PCM16 WAV，保留采样率和完整时长，
没有剪辑、变速或降噪。原始文件也保留在用户数据目录。

## 验证边界

自动测试覆盖隐藏、重启读取、部分恢复、升级去重、草稿/工程快照、空音色库操作，
以及模拟采集的停止、30 秒上限、短录音、静音、设备/权限错误、重录和取消清理。
这些测试不能代替实际麦克风验收。真实录音需由用户在安装版点击开始、朗读、停止和
保存，再验证保存后的声音可重启复用和实际合成。最终本机验收情况记录在交付报告中。

同日用户在安装版使用 WH-1000XM3 麦克风录制了 9.868 秒，得到 24 kHz 单声道 PCM16。
首次保存后读取暴露了 Windows AppData 路径别名误判，录音文件本身已完整保存。
修复改为核对目录的文件系统身份，继续拒绝越界引用；重新读取原录音，已在上述
RTX 2070 SUPER 环境实际生成 8.92 秒配音。保存失败时另保留 WAV、名称和原文的
恢复副本，避免用户需要重新录制。
