# 配音引擎验收记录

日期：2026-09-09。实机为 NVIDIA GeForce RTX 2070 Super，8GB 显存，
计算能力 7.5。模型为 Fun-CosyVoice3-0.5B-2512。

## 修复与自动化验证

修复了 Windows 工作进程启动后无响应的问题。堆栈诊断显示，控制线程阻塞读取
标准输入时，主线程停在 NumPy 原生模块初始化；相同 Python 单独导入 NumPy
只需约 0.2 秒。Windows 管道现使用 PeekNamedPipe 检查可用字节，再执行读取，
避免后台线程持有阻塞读取锁。模型仍由独立工作进程按需加载。

七项引擎/协议测试通过，覆盖完整多段合并、取消后复用完整分段、损坏分段缓存
重新生成、静音输出拒绝、参数校验、第三方输出与协议隔离、无效请求恢复、取消/重试和显存
不足的错误映射。协议测试也在实际 Python 3.10 推理环境下运行通过，包含
启动控制线程后再导入 NumPy 的回归场景。控制线程发生意外异常时返回 control_failed、完整错误堆栈与退出码 2；覆盖启动和任务处理中两种场景。

## 原有 CUDA 12.1 环境实机结果

Python 3.10.21，PyTorch 2.3.1+cu121，CUDA 12.1。

| 场景 | 结果 |
|---|---|
| CUDA 矩阵计算与模型短句自检 | 通过；加载约 28.59 秒，生成 4.92 秒语音约 10.55 秒 |
| 四段长文本取消 | 在完整分段边界取消，未发布不完整输出 |
| 取消后重试 | 复用前两段，得到 52.96 秒完整音频，重试约 46.70 秒 |
| 切换 FLEURS 女声参考录音 | 通过；得到 4.32 秒音频，生成约 9.34 秒 |

结果均为 24 kHz PCM WAV，可解码、数值有限且非静音。检查的是模型实际输出
及文件有效性，未进行人工听感评分。以上取消使用协议的分段边界机制；界面的
10 秒强制停止与进程树清理由另一个 Qt 测试覆盖。

其他显卡仍需独立实机验证。运行包在 2070 Super 上通过，不等于 RTX 30、40、
50 或笔记本型号已经验收。

## 可分发 CUDA 12.8 环境实机结果

独立组装的 Python 3.10.21、PyTorch 2.7.1+cu128、torchaudio 2.7.1 运行包，
在同一台 2070 Super 上完成 CUDA 实际运算及完整模型短句合成。加载约 106.56
秒，生成约 13.41 秒，得到 4.96 秒、24 kHz 的有效非静音音频。该次启动处于
运行包首次使用及并行打包期间，时间不作为稳态性能基准。

此项验证说明新运行包的模型 API 兼容性，**不构成 RTX 50 实机验证**。

## 可分发 CUDA 12.1 环境的中文及空格路径

独立运行包通过包含“中文路径 空格验证”的新目录启动，实际完成 CUDA 运算、
模型加载及短句生成。Python 3.10.21、PyTorch 2.3.1+cu121；加载约 72.56 秒，
生成约 13.04 秒，得到 4.92 秒、24 kHz 的有效非静音音频。

测试目录是系统 Temp 内真实的目录树，文件使用 NTFS 硬链接以避免重复存放
数 GB 运行文件；未使用目录联接，Python/DLL 解析使用新的中文及空格路径。
该次验证检查路径可移植性，发行压缩包仍包含普通文件。启动使用 `-B`，所有
缓存和输出另存于测试临时目录，运行包文件未被修改。
