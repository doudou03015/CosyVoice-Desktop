# 主屏启动位置修复

2026-09-10，本机修复构建，基于试听修复与统一图标版本；未替换已发布的 alpha.1 附件。

每次启动先选定 Windows 主显示器，再使用 Qt 的逻辑坐标和主屏可用区域计算位置。
窗口完整边框居中，并为任务栏及屏幕边缘留出空间。首次显示后按实际边框再校正一次；
用户之后拖动、隐藏或再次显示窗口时不会被自动移回。不同显示器的缩放比例不混用。

主屏空间较小时会适当缩小窗口，页面内容可以滚动，播放状态、任务进度和取消按钮保持可见。
试听输出设备刷新、播放进度和错误提示，以及 EXE、任务栏、窗口与侧栏图标均保留。

验证使用锁定的 PySide6/Qt 6.11.2。桌面回归合计 62 项测试和 20 项子测试通过，
包含负坐标、多屏缩放后的可用区域、小屏滚动、首次显示生命周期和实际 FFmpeg 编码检查。
本机三屏环境的源码实测：主屏可用区域为 `(0, 0, 2293, 912)`，
窗口完整边框为 `(506, 16, 1280, 880)`，位于主屏中央且完全可见。

可在安装版中运行不加载模型的窗口位置检查：

```powershell
.\CosyVoice-Desktop.exe --verify-placement --report "窗口位置检查.json"
```

检查会短暂显示独立窗口，记录主屏、窗口边框、可用区域和图标状态后退出。
原有模型、音色、工程和已完成的音频继续保留。
